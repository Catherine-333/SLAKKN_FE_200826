# 🚀 AI Future Explorer

A simple, modern, beginner-friendly single-page website built to introduce core concepts of Artificial Intelligence, the 2030 vision, developer roadmaps, and AI safety principles.

---

## 🛠️ Technologies Used

- **HTML5**: Clean, semantic structure.
- **Tailwind CSS (via CDN)**: Modern styling with zero build configuration needed.
- **JavaScript (Vanilla JS)**: Lightweight script for mobile responsiveness and navigation.

---

## 📂 Project Structure

```text
AI-Future-Explorer/
├── index.html      # The entire single-page website with all 7 sections
├── script.js       # Simple JavaScript for menu toggle and interactions
└── README.md       # Project guide and instructions
```

## 🖥️ How to Run This Project in VS Code (Beginner Guide)

You have two easy ways to run and view this website on your computer:

### Option 1: Using the "Live Server" Extension (Recommended)

1. **Open VS Code**.
2. Go to **File** > **Open Folder...** and select this `AI-Future-Explorer` folder (`d:\SLAKKN_FE_200826\Trailwind\Day4\AI-Future-Explorer`).
3. Open the **Extensions** panel in VS Code (press `Ctrl + Shift + X` on Windows).
4. In the search bar, type **`Live Server`** (by *Ritwick Dey*) and click **Install**.
5. Once installed, open `index.html` in VS Code.
6. Right-click anywhere in the code editor and select **"Open with Live Server"** (or click **"Go Live"** in the bottom-right status bar of VS Code).
7. Your default browser will automatically open with the website running at `http://127.0.0.1:5500/index.html`! Any edits you save will automatically refresh in your browser.

---

### Option 2: Open Directly in Your Browser (No Extensions Needed)

1. Open **File Explorer** in Windows.
2. Navigate to:
   `d:\SLAKKN_FE_200826\Trailwind\Day4\AI-Future-Explorer`
3. Double-click **`index.html`** (or right-click and select **Open with** > **Google Chrome** / **Microsoft Edge** / **Firefox**).
4. The website will immediately load and function in your browser!

## 🧭 Sections Included

1. **Navbar**: Brand title, desktop links, and mobile-friendly hamburger menu.
2. **Hero Section**: Catchy title, subtitle, and an *"Explore Future"* smooth scroll button.
3. **AI Today**: 3 informative cards describing **OpenAI**, **Anthropic**, and **Google Gemini**.
4. **Future 2030**: 4 cards highlighting **AI Agents**, **AI in Software Development**, **AI in Education**, and **AI in Cybersecurity**.
5. **Developer Roadmap**: Visual 7-step learning guide from HTML/CSS to real-world AI Projects.
6. **AI Safety**: 5 pillars covering Human Control, Testing, Privacy, Security, and Responsible AI.
7. **Footer**: Clean branding statement *"AI Future Explorer – Learn, Build and Explore"* with quick links and automatic current year.
